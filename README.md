# 📚 Learning Management System (LMS)

## 📌 Description
Learning Management System (LMS) is a web-based application developed to support digital learning processes.  
This system allows users to manage courses, categories, and basic learning content efficiently.

This project was built as part of a full-stack web development learning journey, focusing on building structured and scalable systems.

---

## 🚀 Features
- Landing page for LMS
- Course page display
- About page
- Simple UI design
- Static content structure

---

## 🛠️ Tech Stack
- HTML
- CSS
- XAMPP (Local Server)
